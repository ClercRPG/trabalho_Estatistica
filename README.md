# 📊 Dashboard de Análise de Vendas

Este projeto foi desenvolvido como parte de um trabalho de análise descritiva, com o objetivo de explorar dados de vendas e apresentar resultados de forma visual e interativa.

---

## 🚀 Tecnologias utilizadas

- Python
- Pandas
- Streamlit
- Matplotlib
- Altair

---

## 📁 Estrutura do Projeto

- `app.py` → Aplicação principal (dashboard)
- `Trabalho Análise Exploratória (1).xlsx` → Base de dados utilizada

---

## 📊 Funcionalidades do Dashboard

O dashboard apresenta:

### 🔹 Tópico 1
- Criação da variável **Total_Sale**

### 🔹 Tópico 2
- Tabelas de frequência
- Distribuição por continente e categoria
- Vendas por mês

### 🔹 Tópico 3
- Tabelas cruzadas entre:
  - Categoria × Continente
  - Continente × Mês
  - Categoria × Mês

### 🔹 Tópico 4
- Medidas descritivas:
  - Média
  - Mediana
  - Moda
  - Variância
  - Desvio padrão
  - Quartis
  - IQR

### 🔹 Tópico 5
- Gráficos:
  - Histograma
  - Boxplot
  - Gráfico de barras
  - Gráfico de linha
  - Gráfico de pizza
  - Top 10 países
